AI Chat – Fullstack додаток (Node.js + Quasar)

Повноцінний чат-додаток з інтеграцією OpenAI API. Бекенд побудовано на Node.js + Express + Supabase (PostgreSQL), фронтенд — на Quasar (Vue 3, TypeScript, Vite). Проєкт реалізовано у форматі монорепозиторію — обидві частини знаходяться в одному репозиторії.

-------------------------------------------------------------------------------
ВИМОГИ
-------------------------------------------------------------------------------
Node.js v18 або новіше
npm або yarn
Обліковий запис Supabase (безкоштовний)
API ключ OpenAI

-------------------------------------------------------------------------------
ШВИДКИЙ СТАРТ
-------------------------------------------------------------------------------
1. Клонувати репозиторій:
   git clone <url> my-chat-app
   cd my-chat-app

2. Встановити кореневі залежності (для запуску обох серверів з однієї команди):
   npm install

3. Встановити залежності для бекенду та фронтенду:
   npm run install:all
   (або вручну: cd backend && npm install && cd ../frontend && npm install)

4. Налаштувати змінні оточення:
   Скопіюйте backend/.env.example -> backend/.env і заповніть його (див. розділ "Конфігурація" нижче).
   Для фронтенду змінні оточення не потрібні (використовується проксі).

5. Запустити одночасно бекенд і фронтенд:
   npm run dev
   Бекенд: http://localhost:3000
   Фронтенд: http://localhost:8080

-------------------------------------------------------------------------------
КОНФІГУРАЦІЯ БЕКЕНДУ (файл backend/.env)
-------------------------------------------------------------------------------
PORT=3000
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
LOG_LEVEL=info
# USE_MOCK_OPENAI=true   # якщо хочете тестувати без реальних запитів до OpenAI

Де взяти значення:
- SUPABASE_URL – у Supabase Dashboard -> Settings -> API -> Project URL.
- SUPABASE_ANON_KEY – там само, скопіюйте anon public (не service_role).
- OPENAI_API_KEY – на OpenAI Platform -> API keys.
- OPENAI_MODEL – залиште gpt-4o-mini (дешева модель) або змініть.
- LOG_LEVEL – debug для детальних логів, info для звичайного режиму.

-------------------------------------------------------------------------------
НАЛАШТУВАННЯ БАЗИ ДАНИХ (SUPABASE)
-------------------------------------------------------------------------------
1. Увійдіть у Supabase Dashboard -> оберіть проєкт.
2. Перейдіть у SQL Editor.
3. Виконайте скрипт backend/supabase/migrations/init.sql – він створить таблиці sessions, messages, model_pricing, тригери.
4. Виконайте скрипт backend/seed/pricing.sql – додасть початкові ціни для моделей OpenAI.

Якщо ви хочете тимчасово вимкнути RLS (для спрощення тестування), виконайте у SQL Editor:
ALTER TABLE sessions DISABLE ROW LEVEL SECURITY;
ALTER TABLE messages DISABLE ROW LEVEL SECURITY;

API ENDPOINTS
-------------------------------------------------------------------------------
POST   /sessions                      Створити нову сесію.
          Тіло: { "model": "gpt-4o-mini", "system_prompt": "..." }

POST   /sessions/{id}/messages        Надіслати повідомлення.
          Тіло: { "content": "Привіт!" }

GET    /sessions/{id}                 Отримати сесію з повною історією та накопиченою вартістю.

-------------------------------------------------------------------------------
ПРИКЛАДИ ЗАПИТІВ (CURL)
-------------------------------------------------------------------------------
1. Створити сесію:
curl -X POST http://localhost:3000/sessions \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","system_prompt":"You are a helpful assistant."}'

Відповідь:
{
  "id": "abc-123",
  "title": null,
  "model": "gpt-4o-mini",
  "system_prompt": "You are a helpful assistant.",
  "total_cost_usd": 0,
  "created_at": "2026-08-19T...",
  "updated_at": "2026-08-19T..."
}

2. Надіслати повідомлення:
curl -X POST http://localhost:3000/sessions/abc-123/messages \
  -H "Content-Type: application/json" \
  -d '{"content":"Привіт, як справи?"}'

Відповідь:
{
  "message": { ... },
  "usage": { "prompt_tokens": 10, "completion_tokens": 15, "total_tokens": 25 },
  "cost": 0.000015
}

3. Отримати сесію з історією:
curl http://localhost:3000/sessions/abc-123

Відповідь: об'єкт сесії з полем messages (масив повідомлень) та total_cost_usd.

-------------------------------------------------------------------------------
ВИКОРИСТАНІ ТАРИФИ
-------------------------------------------------------------------------------
Модель за замовчуванням: gpt-4o-mini
Input: $0.000150 / 1K tokens
Output: $0.000600 / 1K tokens

Ціни зберігаються в таблиці model_pricing і можуть бути оновлені без передеплою.

Якщо SDK повертає додаткові категорії usage (наприклад, cached_tokens), вони не враховуються у вартості (залишено поза скоупом MVP).

-------------------------------------------------------------------------------
РОЗРОБКА ТА НАЛАГОДЖЕННЯ
-------------------------------------------------------------------------------
Бекенд автоматично перезавантажується завдяки nodemon.
Фронтенд має hot-reload (Vite).
Проксі у фронтенді (/api -> http://localhost:3000) дозволяє уникнути CORS при розробці.
Для логування використовується pino – рівень логування налаштовується через LOG_LEVEL.
